Objective Question Bank & Dynamic Formation Engine (v1.7.0)

Latest Production Release • Complete Feature Planning, Design & Logic
Latest Release

A major architectural leap introducing the Universal Objective CSV Engine, deterministic Question Formation Normalization, and interactive Live Question Previews. Import hundreds of Multiple Choice Questions (MCQs), Fill in the Blanks (FIBs), and True/False questions in seconds with zero data loss and automated syntax repair.

📐 Feature Planning & Architectural Logic

Standard question banks frequently struggle when importing CSVs due to Excel UTF-8 BOM byte order marks (\uFEFF), embedded multi-line cells containing line breaks inside quotes, inconsistent delimiter conventions (semicolons, commas, tabs), and accidental question numbering or option prefixes. The v1.7.0 engine implements a multi-stage offline pipeline:

1. Ingestion & BOM Stripping
Strips UTF-8 BOM headers (\uFEFF, \uEFBBBF) and auto-detects delimiters (, vs ; vs \t).
2. RFC-4180 State Machine
Character-by-character tokenizer perfectly preserves line breaks inside multi-line quoted questions and explanations.
3. Question Formation Logic
Strips redundant prefixes (Q1., A)) and separates explanations from correct answers (splitAnswerAndExplanation).
4. Dual Room Routing & Resiliency
Non-blocking partial imports populate question_bank and flashcards; invalid rows are skipped without halting valid items.
